# Updates

Each `.md` file in this folder is one post on theruncheck.app/updates.
The file name becomes the link, so `paid-runs.md` lives at /updates/paid-runs.

To add a post, copy any post below, rename it, and change the top part:

```
---
title: The headline
date: 2026-11-20
image: /photos/pickup-night.webp
focus: 50% 40%
summary: One short line that shows on the card and when the link is shared.
---
```

`focus` is optional. It picks which part of a tall photo shows on the card: `50% 20%` keeps the top, `50% 80%` keeps the bottom.

Under that, just write. A blank line starts a new paragraph.

- `## Something` makes a small heading
- `- item` makes a bullet list
- `**words**` makes words bold
- `[words](/merch)` makes a link

Posts show newest first by date. This README is not a post.

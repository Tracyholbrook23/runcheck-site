A lot of the best runs happen in gyms that cost money to rent. Now the host can set a price for the run right in RunCheck, and players pay in the app when they join.

## How paying works

- When you join a paid run, we put a **hold** on your card. A hold is not a charge.
- You're only charged when the run **locks**, which happens when enough players join.
- If the run never locks, nobody is charged and the hold goes away.
- You can leave for free anytime before the run locks.

## If plans change

- If the host cancels, everybody gets a full refund automatically.
- If the host changes the date, time or place after you joined, you can leave and get everything back.
- After the run locks, tap **Give up my spot**. If another player takes it, you get the run price back.

Want to see it in action? [Open Run Elite](/updates/open-run-elite) at Round Rock Sports Center is already using it.

Every detail is on our [refund policy](/refunds). Hosts, this means the court gets paid for before anybody steps on it.
